# Duit Masuk — versi pertama

Ini ialah prototaip aplikasi kewangan yang boleh dipasang sebagai PWA (Progressive Web App) pada Android/iPhone melalui browser yang menyokong pemasangan.

Fungsi:
- Duit Masuk / Duit Keluar
- Item Beli
- Akaun
- Baki semasa
- Simpan data dalam telefon menggunakan localStorage
- Boleh digunakan tanpa server selepas pertama kali dimuatkan

Cara cuba:
1. Buka `index.html` melalui hosting HTTPS (contohnya GitHub Pages/Netlify).
2. Buka laman itu pada telefon.
3. Pilih “Add to Home Screen / Tambah ke Skrin Utama”.
